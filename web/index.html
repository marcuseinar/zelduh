About the graphics

The art that ships with the game is original. Nothing from any commercial cartridge is included or downloaded.

If you own a Game Boy game, you can drop its ROM here and the engine will read tiles out of your own file to draw the world with. Nothing is uploaded: the file is read in this tab and never leaves your machine.

A cartridge does not record where its graphics live, so a plain ROM gives a remix rather than a faithful tileset. A .zprofile file pins that down — it says which tiles to import and what each one should be used for.
